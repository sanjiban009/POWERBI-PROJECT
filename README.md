Accounts Receivable & Working Capital Intelligence | Power BI & Interactive HTML Dashboard

Developed a multi-page financial intelligence portfolio project for a synthetic FMCG distribution business, featuring an interactive Power BI-inspired dashboard with 10 analytical pages and 15,120 records across 11 data tables.

Key Highlights:

- Analyzed Accounts Receivable, Accounts Payable, Collections, Inventory and Working Capital.
- Developed financial KPIs covering DSO, DPO, DIO, Cash Conversion Cycle, overdue balances, credit exposure and liquidity.
- Created interactive dashboards with dynamic filtering, drill-down functionality, colourful visualizations and data labels.
- Built a self-contained offline HTML dashboard using JavaScript, enabling browser-based analysis without Power BI Service.
- Included historical trends, customer/supplier segmentation, ageing analysis and exportable data views.

Technologies: Power BI, DAX, Excel, Data Modeling, HTML, CSS and JavaScript.

**Business Objective:** Improve financial visibility, identify credit and collection risks, and support working-capital decision-making.

Portfolio demonstration using synthetic financial data.
